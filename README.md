# Scientific articles

Сайт кафедры ИУ5: студент подаёт статью, преподаватель её проверяет и выносит
решение, студент видит результат в личном кабинете.

Референс по функционалу — <https://conference.kf.bmstu.ru/> (приём заявок, архив,
документы). Ориентир по внешнему виду — <https://bmstu.ru/>.

**Статус:** версия 1.0 в разработке.

## Что делает версия 1.0

Две роли и один прямой путь статьи:

```
Студент ──подаёт статью, выбирает преподавателя──> в кабинет преподавателя
                                                        │
Преподаватель ──читает файл──> Одобрить ────────────────┤
                          └──> Отклонить + причина ─────┘
                                                        │
Студент <──статус и причина отказа в личном кабинете────┘
```

- **Регистрация и вход** — логин, почта, пароль. Роль выбирается при регистрации:
  студент или преподаватель.
- **Кабинет студента** — список своих статей, подача новой: название, аннотация,
  файл, выбор преподавателя. В карточке — статус, решение и причина отказа.
- **Кабинет преподавателя** — очередь статей, которые выбрали его. В карточке:
  метаданные, скачивание файла, кнопки «Одобрить» и «Отклонить»; при отказе причина
  обязательна.
- **Права** — файл статьи открывается только автору и выбранному преподавателю.
  Проверка на сервере, а не сокрытием кнопок в интерфейсе.

**Чего в 1.0 нет** (осталось в ТЗ, придёт следующим слоем): конференций и секций,
дедлайнов, оргкомитета, версий файла и доработки, писем, проверки оригинальности,
ассистента на нейросети.

## Стек

| Слой | Выбор |
|---|---|
| Фреймворк | Next.js, App Router |
| Язык | TypeScript |
| База | SQLite через Prisma (на деплое — PostgreSQL) |
| Стили | Tailwind CSS, собственные компоненты на токенах МГТУ |
| Авторизация | собственная: `scrypt` из `node:crypto`, сессия в подписанной httpOnly-cookie |
| Валидация | zod |
| Файлы | папка `var/uploads`, раздача через `/api/files/[id]` с проверкой прав |
| Тесты | Vitest |

Обоснование и отвергнутые альтернативы — [`docs/тз.md`, раздел 13](docs/тз.md).

## Запуск локально

```bash
npm install
npx prisma migrate dev        # создаёт prisma/dev.db и применяет схему
npm run db:seed               # преподаватели для выбора + тестовые аккаунты
npm run dev                   # http://localhost:3000
```

Тестовые аккаунты создаются сидом, пароли лежат в `prisma/seed.ts`.

## Структура репозитория

```
app/
  page.tsx                 главная
  login/ register/         вход и регистрация
  cabinet/                 кабинет студента: список, подача, карточка статьи
  teacher/                 кабинет преподавателя: очередь, карточка проверки
  api/files/[id]/          выдача файла с проверкой прав
lib/                       бд, сессии, пароли, роли, валидация
prisma/                    схема, миграции, сид
docs/                      ТЗ и план
var/uploads/               файлы статей (в git не попадает)
```

## Дизайн

Токены сняты с `bmstu.ru`: акцент `#006CDC`, текст `#303030`, светлые подложки
`#F8F9FA`, скругления карточек 12px, кнопки-«таблетки». Шрифт —
`'ALS Sector', 'Golos Text', system-ui`: ALS Sector платный, в работе используется
свободный Golos Text, платный подставляется одной строкой, если появится лицензия.
Герб и логотип МГТУ не используем без разрешения кафедры.
